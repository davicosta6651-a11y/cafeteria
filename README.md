☕ Site de Cafeteria

Bem-vindo ao projeto do site de uma cafeteria!

Este projeto tem como objetivo criar um site moderno, bonito e responsivo para apresentar uma cafeteria, seus produtos e informações de contato.

📖 Sobre o projeto

O site foi desenvolvido para proporcionar uma experiência agradável aos visitantes, apresentando o ambiente da cafeteria, seu cardápio e os principais produtos oferecidos.
